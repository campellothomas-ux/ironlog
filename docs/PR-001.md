# Base Vite/TypeScript et fin de séance fiable

La V4 annonçait une séance enregistrée même lorsque localStorage refusait l'écriture. La fin de séance prépare maintenant le nouvel état, écrit l'activité et la suppression de séance active en une seule opération, puis affiche la liste Activités. En cas d'erreur, elle conserve la séance et propose de réessayer. Une identité stable par séance démarrée évite les doublons dans un même onglet.

## Modifications

- `index.html`, `src/main.ts`, `src/legacy.ts`, `src/styles.css` : extraction fidèle du prototype, conservé intact à la racine. Le module legacy reste temporairement sans contrôle TypeScript/lint.
- `src/storage.ts`, `src/workout/complete.ts` : compatibilité de clé V4, persistance et transition typées.
- Manifeste npm et lockfile, TypeScript, ESLint, Vitest, Playwright, CI GitHub : base de développement reproductible.
- `netlify.toml`, README : build et instructions de site de test distinct, sans déploiement production.
- Audit, tests du domaine, intégration DOM et parcours WebKit.

## Validation locale
