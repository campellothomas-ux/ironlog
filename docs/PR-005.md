# Préparer un premier test Web Push isolé

Le chrono persistant ne peut pas déclencher seul une notification sur iPhone verrouillé. Cette branche prépare l'étape préalable : permission volontaire, souscription Push, association par code secret à une installation, Worker Cloudflare SQLite, notifications test immédiate ou différée (30/90 s) et désactivation. Le prototype est inactif sans configuration et indique que les alertes de repos ne sont pas programmées.

Le Worker limite les accès, contrôle l'origine et les jetons, restreint les destinations Push et ne reçoit aucune donnée d'entraînement. Les identifiants d'installation sont séparés des sauvegardes. La clé VAPID privée et le code restent des secrets serveur. [Guide de configuration et de validation](WEB-PUSH-PROTOTYPE.md).

Le Worker a été compilé en mode `--dry-run`, et l'appairage/CORS/désactivation a été testé localement avec des données fictives ; le chiffrement VAPID et les refus sont testés avec un fournisseur simulé. Aucun service distant n'a été provisionné. Aucun test Apple, iPhone verrouillé, quota CPU réel ou réception effective n'a eu lieu. Les alarmes de test différé et leur annulation sont couvertes par simulation. Leur réception et leur précision restent à vérifier sur iPhone. L’intégration au chrono reste à réaliser après la première réception réelle ; aucune annulation de repos à distance n’est revendiquée.

Avant déploiement : autorisation explicite, compte Cloudflare Free, revue de sécurité et configuration des secrets directement chez le propriétaire. Préserver une sauvegarde externe avant installation de la preview sur l'iPhone. Ne pas fusionner ou modifier la production avant validation réelle.

Vérifications exécutées : installation `npm ci`, lint, compilation TypeScript du Worker, build Vite, 44 tests dans chacun des fuseaux Paris/New York et 75 parcours Chromium sur cinq formats. Les tests des alarmes, du chiffrement et du service worker utilisent des fournisseurs et événements simulés ; aucune autorisation ni réception iOS réelle n'est revendiquée. L'accès à la documentation Cloudflare a été vérifié via ses sources publiques officielles ; les quotas applicables sont détaillés dans le guide.
